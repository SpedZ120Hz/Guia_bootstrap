Grid — o esqueleto da página

Três classes que trabalham juntas: container limita a largura, row cria uma linha, col-* divide essa linha em colunas de 1 a 12.

.containercentraliza o conteúdo e dá uma largura máxima responsiva

Renderizado

conteúdo centralizado

Código

<div class="container">
  conteúdo centralizado
</div>
.row + .col-md-*divide o espaço em colunas — a soma dos números deve dar 12

Renderizado

col-md-7
col-md-5

Código

<div class="row">
  <div class="col-md-7">...</div>
  <div class="col-md-5">...</div>
</div>

Espaçamento

Padrão: {propriedade}{direção}-{tamanho}. Propriedade: m (margin) ou p (padding). Direção: t topo, b baixo, s início, e fim, x horizontal, y vertical (vazio = todos os lados). Tamanho: 0 a 5.

.p-4 · .mt-3 · .mb-2padding e margin prontos, sem precisar escrever CSS

Renderizado

p-4 (padding em todos os lados)
mt-3 (margin no topo)

Código

<div class="p-4 mb-2">...</div>
<div class="mt-3">...</div>

</div>

Navbar

É a combinação que te pegou: navbar-expand-md decide a partir de qual largura o menu vira horizontal; sem ela, fica sempre colapsado.

.navbar + .navbar-expand-mdestrutura base + regra de responsividade do menu

Renderizado (redimensione a janela pra ver o efeito)

Marca
  • Início
  • Sobre

Código

<nav class="navbar navbar-expand-md">
  <a class="navbar-brand" href="#">Marca</a>
  <button class="navbar-toggler"
    data-bs-toggle="collapse"
    data-bs-target="#exNav">
    <span class="navbar-toggler-icon"></span>
  </button>
  <div class="collapse navbar-collapse" id="exNav">
    <ul class="navbar-nav ms-auto">
      <li class="nav-item">
        <a class="nav-link" href="#">Início</a>
      </li>
    </ul>
  </div>
</nav>

Componentes com JavaScript

Esses só funcionam com o bootstrap.bundle.min.js carregado. O padrão é sempre: data-bs-toggle="tipo" diz qual comportamento; data-bs-target="#id" diz qual elemento ele controla.

data-bs-toggle="collapse"esconde/mostra um bloco — usado no menu mobile
<button data-bs-toggle="collapse" data-bs-target="#alvo">Abrir</button>
<div class="collapse" id="alvo">Conteúdo escondido</div>
data-bs-toggle="modal"abre uma janela sobreposta (popup)
<button data-bs-toggle="modal" data-bs-target="#meuModal">Abrir</button>
<div class="modal" id="meuModal">...</div>
data-bs-toggle="dropdown"menu suspenso ao clicar
<button class="btn btn-primary dropdown-toggle" data-bs-toggle="dropdown">
  Menu
</button>
<ul class="dropdown-menu">
  <li><a class="dropdown-item" href="#">Opção</a></li>
</ul>

Cobre o essencial pra sair do zero. Pra tudo, a documentação oficial tem cada classe: getbootstrap.com/docs.
